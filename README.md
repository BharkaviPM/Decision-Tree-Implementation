## **Project Overview**

This repository contains the implementation and visualization of a **Decision Tree** model using **scikit-learn** in **Python**. The project demonstrates how to classify or predict outcomes on a dataset, specifically using the classic **Iris dataset**. The primary aim is to showcase the end-to-end workflow of building, visualizing, and analyzing a machine learning model in a reproducible and interpretable manner.

---

## **Motivation**

The motivation behind this project is to gain hands-on experience with one of the most interpretable machine learning algorithms-**Decision Trees**. By working with the Iris dataset, the project provides a clear and educational example of how to approach classification problems, visualize model decisions, and evaluate performance. This project also serves as a foundational step for more advanced machine learning tasks and helps in understanding the importance of model interpretability and workflow documentation[1][3][5].

## **Tools and Technologies**

- **Matplotlib:** Visualization library for plotting the Decision Tree.

## **Dataset**

The **Iris dataset** is a well-known dataset included in scikit-learn. It contains 150 samples of iris flowers, each described by four features (*sepal length, sepal width, petal length, petal width*) and classified into one of three species. This dataset is ideal for demonstrating classification algorithms due to its simplicity and balanced class distribution.

---

## **Workflow**

1. **Data Loading and Preparation:**  
   - Load the Iris dataset.
   - Split data into features (**X**) and target labels (**y**).
   - Divide the data into training and testing sets.

2. **Model Building:**  
   - Initialize and train a `DecisionTreeClassifier` on the training data.

3. **Visualization:**  
   - Visualize the trained Decision Tree using `plot_tree` from scikit-learn, providing a clear graphical understanding of the decision-making process.

4. **Evaluation:**  
   - Assess the model’s predictive performance using accuracy and a detailed classification report (precision, recall, F1-score).
